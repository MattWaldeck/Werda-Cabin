# Werda-Cabin

Website for Werda Cabin, a cosy tiny home on a working farm in the Tulbagh Valley, South Africa.
Live at https://www.werda-cabin.co.za

## Pages

| URL | File |
| --- | --- |
| `/` | `index.html` |
| `/cabin/` | `cabin/index.html` |
| `/gallery/` | `gallery/index.html` |
| `/reviews/` | `reviews/index.html` |

The four pages share the same header, footer and booking section. They are generated by
`scripts/generate-pages.py` (run `python3 scripts/generate-pages.py` from the repo root).
Edit the generator rather than the HTML files, or your changes will be overwritten next time it runs.

## Images

Originals live in `img/`. The site uses optimised WebP copies in `img/web/`
(`Name.webp` at 1600px and `Name-sm.webp` at 800px). `public/og-image.jpg` is the 1200×630 social share image.

## Development

```bash
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
npm run lint
```

Deployed on Vercel (`vercel.json`).
